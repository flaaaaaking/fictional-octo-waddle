# 测试、实验代码与验收

## 实验代码规则

每一次消耗名额的完整试验，都要记录实验编号、实验代码／访问码、环境、提交版本、问题轮数、报告结构、恢复结果、发现的问题和修正提交。

访问码同时充当单次实验代码。模拟测试代码可以记录在仓库；真实用户代码不得公开。

实验编号格式：EXP-日期时间-访问码前缀。

## 自动验收脚本

只读检查，不消耗名额：

    .\scripts\smoke-test.ps1 -BaseUrl "https://你的服务地址"

完整模拟，会消耗一个名额：

    .\scripts\smoke-test.ps1 -BaseUrl "https://你的服务地址" -ConsumeSlot

脚本会输出实验编号、实验代码、结果链接、五维数量、子特质数量和报告恢复状态。

## 发布验收清单

- 首页、全家福和五张单人图成功加载；
- 01–05 与全家福是同一人物；
- 桌面端与移动端可读；
- 今日名额正确；
- 领取后出现实验代码；
- 无有效代码不能读取会话；
- 一次只显示一个开放问题；
- 报告包含五维和 15 子特质；
- 倾向区间与证据可信度没有混淆；
- 同一代码可以恢复报告；
- 前端不存在 DeepSeek API Key；
- 页面明确说明非量表、非诊断。
